01 · rooms of the hall

Inside the hall

Six rooms. One for every way a daemon can need you.

The Hall

Every watched unit as a card: state, uptime, CPU, memory, restarts. Filter by what's failing; start, stop or restart from the card.

system + user units

Live logs

The journal, streamed as it's written. Filter, show only warnings or errors, pause, follow. Colour codes cleaned up.

server-sent events

The Chronicle

Every start, stop, crash and auto-restart, read from systemd's own records, so history goes back further than DaemonHall does.

repeats folded ×N

The Clockwork

All your timers with their real next and last run and the last result. Run any of them now, or switch one off.

calendar + interval timers

The Summoning Room

Create a service from a form, with a live preview of the unit file: hardened by default, optional schedule, verified before it's installed.

user or system

Hauntings

03 · wards & seals

It can stop your services.
So it's built to be boring to attack.

Localhost, checked twice

Bound to 127.0.0.1, and every request must say Host: 127.0.0.1:8767, which shuts out DNS-rebinding tricks.

A token per run

Every change needs a fresh token from the page plus a matching Origin. Another tab in your browser can't read it, so it can't forge a click.

Polkit, scoped tight

Only you, only the units you watch, only hand-installed files in /etc/systemd/system. Distro units and everything else still ask for a password.

No raw unit text

New units are written by a tiny root helper from validated fields: User= forced to you, no + prefixes, % escaped, systemd-analyze verify first.

Everything on the record

Every action from the hall lands in the Chronicle, marked "via hall", next to what systemd itself saw.

Backups before burial

Deleting a unit stops, disables and removes it — and keeps a copy first. Editing a system unit is sudoedit: your password, every time.

05 · the ritual

Summon it

Two steps. The second is only for controlling system services; user services work without it.

I

Build & start

git clone https://github.com/cybercore-tech/DaemonHall
cd DaemonHall
./packaging/install.sh

Installs ~/.local/bin/daemonhall and a user service, then opens on 127.0.0.1:8767.

II

Bind the seals (optional)

sudo ./packaging/install-root.sh

Installs the root helper and a polkit rule scoped to your watched units. Undo with --uninstall.

III

Needs

  • Linux with systemd
  • Rust (stable)
  • cybercore and cyberwatch checked out in ~/.sysops
  • A browser. That's it.
